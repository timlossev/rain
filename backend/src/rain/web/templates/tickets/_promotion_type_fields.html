Promotion type

Every match becomes its own new ticket.

If a match's computed title (below) equals an already-open ticket of this type, the event is added to that ticket as a "last occurred on ..." comment and the ticket is flagged Problematic, instead of creating a new ticket. No open match → a new ticket is created as usual.

Learns what's typical for these repeated events (severity, length, time of day) and adds a note to the ticket when one stands out - using the standard settings below, no extra tuning needed. Leave this checked unless you'd rather skip it.
None scores every matching event with one model. Host/program keeps a separate model (and cooldown) per value.
Learns what's normal from each matching event's severity, length, and time of day - no threshold count to tune by hand. Score is 0-1 (higher = more unusual); it stays quiet until it's seen the warm-up count of events, so a brand new policy doesn't flag its own cold start. Runs alongside single/repetition policies, not instead of them - it never "wins" an event away from them.
