{% extends "base.html" %} {% block title %}Import Tickets - {{ branding.instance_name }}{% endblock %} {% block help_text %}Upload a CSV, JSON, or vulnerability scan export (Nessus .nessus, OpenVAS/GVM XML, or an Amazon Inspector findings report), then map its columns to ticket fields on the next screen (a scan export arrives pre-mapped, still reviewable there). Each row becomes a new incident or vulnerability - change tickets need an approval flow attached by hand, so they aren't importable here. A .nessus file is the plain-XML scan export ("File > Export > Nessus" on a completed scan), not the separate, proprietary Nessus DB transfer format. An OpenVAS/GVM export is the report's own XML format ("Report > Download > XML" in the GSA web UI, or the same shape from gvm-cli). An Inspector export is its JSON findings report (Findings > All findings > Export findings > JSON, or the CreateFindingsReport API) - the CSV option isn't supported, since AWS doesn't publish a stable column list for it. Either way, Info-level findings are skipped, and each finding is looked up by a scan-derived dedup key, so re-uploading a later scan of the same hosts updates matching tickets instead of duplicating them.{% endblock %} {% block content %}
